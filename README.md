# Plataforma de Gestão de Ginásio

## Descrição

Este projeto foi desenvolvido no âmbito da unidade curricular de Programação Funcional.

O objetivo é criar uma plataforma de gestão de ginásio que permita gerir:
- Sócios
- Treinadores
- Aulas
- Inscrições em aulas

## Estrutura do Projeto

src/
- Model.hs -> Definição dos tipos de dados
- Domain.hs -> Funções do domínio
- TestData.hs -> Dados de teste

app/
- Main.hs -> Programa principal para testes

## Funcionalidades Implementadas na Fase 1

- Modelação do domínio usando data, type e records
- Funções puras para gestão de entidades
- Funções recursivas
- Dados de teste para demonstração

## Como Executar

Abrir o projeto no GHCi:

ghci app/Main.hs

Executar:

main
